Prompt 1

November 18, 2026 Tool: Claude Code (Anthropic)

UH Sugar Land Student Center website (class project) You're helping me with the front end of a class web development project: a website for the new Student Center on the University of Houston Sugar Land campus. Students use it to learn what the center offers, get quick answers, and reserve a room online instead of booking in person. Please help me continue developing this front-end part of my project ## Project structure - index.html: home (hero, "Rooms right now" board, embedded YouTube video, Study/Meet/Relax, hours, Developer Contact) - about.html: About us, Meet the team, Careers - services.html: Study and meeting rooms, Lounge and café, Events - blog.html and post.html: blog list, and a single post loaded by ?id= - faq.html: 5 collapsible questions - booking.html: room booking form - contact.html: contact form and Google Map - references.html: AI prompts, media credits, sources - css/styles.css: all styles; colors and fonts are CSS variables at the top - js/menu.js: builds the menu and footer on every page from SITE_MENU - js/rooms.js: 5 rooms, opening hours, sample bookings, checkAvailability(), saveBooking() - js/booking.js: booking form validation and live availability messages - js/faq.js, js/home.js, js/blog.js, js/contact.js: page-specific scripts ## Course requirements (these must keep working after every change) 1. Homepage with a navigation menu built dynamically with JavaScript (js/menu.js). 2. A "Developer Contact" section on the homepage with a name and uh email. 3. FAQ page with exactly 5 collapsible items. 4. Room booking page with 5 rooms, validation on every field following best practices, and an availability check for each room. Availability is simulated in js/rooms.js. Only checkAvailability() and saveBooking() should talk to the future back end. 5. References page showing every AI prompt I used, word for word. 6. Multimedia hosted remotely and embedded (images and video), not downloaded into the project. 7. Good UI practices: works on phone screens, usable with a keyboard, visible focus, a label on every field, enough color contrast. BASED ON MY PROJECT AS RIGHT NOW AND EVERYTHING I'VE DONE HELP ME CONCLUDE THIS,TAKE ALL TIME NEEDED TO COMPLETE THIS FRONT-END PROJECT

Result: Claude helped me creating this front-end part of the project
